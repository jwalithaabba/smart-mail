4. FEATURE ENGINEERING (Run Step 2)
================================================================================

🐍 2_feature_engineering.py (6.0 KB)
   Purpose: Extract meaningful features from emails
   Input: preprocessed_data.csv OR preprocessed_emails.csv
   Output: engineered_features.csv
   Runtime: 3 seconds
   Usage: python 2_feature_engineering.py
   Why: Transform text/metadata into ML features
   
   Features Extracted:
   Metadata (7 features):
   • Subject length (characters)
   • Body length (characters)
   • Subject word count
   • Body word count
   • Time of day (encoded: morning=1, afternoon=2, evening=3)
   • Recipient count (log scale)
   • Is company sender (yes=1, no=0)
   
   Text Features (50 features):
   • TF-IDF vectorization of email text
   • Captures importance of words
   • Most frequent words in emails
   
   Total: 57 features per email

5. MODEL TRAINING (Run Step 3)
================================================================================

🐍 3_model_training.py (6.5 KB)
   Purpose: Train 4 different ML models
   Input: engineered_features.csv
   Output: 4 model files (*.pkl) + scaler.pkl
   Runtime: 5 seconds
   Usage: python 3_model_training.py
   Why: Create multiple models for comparison
   
   Models Trained:
   1. Logistic Regression
      • Fast, interpretable
      • Baseline model
      • Good for simple patterns
   
   2. Random Forest ⭐ Usually Best
      • Ensemble method
      • Handles complexity
      • Feature importance
   
   3. Support Vector Machine (SVM)
      • Good for high-dimensional data
      • Can capture complex patterns
      • Slower than Random Forest
   
   4. Naive Bayes
      • Lightweight, fast
      • Probabilistic approach
      • Works well with text
   
   Output Files:
   • model_logistic_regression.pkl
   • model_random_forest.pkl
   • model_svm.pkl
   • model_naive_bayes.pkl
   • scaler.pkl (feature scaling)
